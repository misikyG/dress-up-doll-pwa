# dress-up-doll-pwa

紙娃娃系統。

## 功能
- 紙娃娃換裝
- PWA 離線支援
- 可打包下載

## 開發
```bash
npm run dev  # 啟動開發伺服器
```

## 部署
專案使用 GitHub Actions 自動部署到 GitHub Pages。

### 更新部署步驟：
1. 本地修改程式碼。
2. 提交變更：
   ```bash
   git add .
   git commit -m "更新說明"
   ```
3. 推送到 GitHub：
   ```bash
   git push origin main
   ```
4. GitHub Actions 會自動建構並部署。

部署完成後，可在 https://misikyG.github.io/dress-up-doll-pwa/ 存取。
